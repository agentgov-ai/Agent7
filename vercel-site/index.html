Authorization

Turn reviewed capabilities into an authorization contract.

Developers do not need to tag every function manually. AgentGov narrows the codebase into a reviewable set of meaningful capabilities, explains why each one matters, and lets teams approve or edit the authorization model.

1

Scanner Suggests

Static analysis discovers tools, classifies risk, and proposes action types.

→
2

Team Reviews

Engineers approve, edit, or reject each suggestion. Only human-confirmed decisions become policy.

→
3

ACAP Generated

Approved decisions compile into a structured authorization contract the runtime enforces.

capability: refund_execute action_type: write approval_required: true data_classes: - financial - customer_data external_side_effect: true max_amount: 500.00 status: approved reviewed_by: compliance-team

Plain English

This action is allowed only when trusted approval is present. It handles financial and customer data, has an external side effect, and must not exceed $500.

Runtime

Monitor what actually happens at runtime.

Every model call, tool execution, and agent decision is captured as a structured governance event with safe metadata.

POST /refund trace

A single user request triggers a chain of observable events. Each event captures provider, model, tool, status, duration, approval state, data classification, and trace ID—without exposing sensitive content.

P

Privacy-safe by default. No raw prompts or responses stored. Only hashes, metadata, and governance evidence. Content capture is opt-in and redacted.

Integration

Connect the AI stack you already use.

Drop-in adapters capture governance evidence from your existing frameworks. No rewrites, no vendor lock-in.

Codebase Scanner Discovery

Capability discovery through static analysis before any runtime instrumentation is deployed.

agent-governance scan ./my-agent
FastAPI Active

Creates request-level governance traces for backend workflows with route, method, status, and timing.

app.add_middleware(GovernanceMiddleware)
OpenAI Active

Captures model, tokens, latency, prompt hash, and response hash for every API call.

client = wrap_openai(OpenAI(), gov)
Anthropic Active

Messages API calls, stop reason, usage metrics, and error events with full trace correlation.

client = wrap_anthropic(Anthropic(), gov)
LangChain / LangGraph Active

Agent, chain, tool, and LLM events with full run hierarchy and parent/child traces.

chain.invoke(input, config=gov.config())
Custom Python Tools Active

Refunds, emails, invoices, database updates—any Python function with side effects.

@gov.tool(action="write", data=["financial"])
Application Logs Supported

Converts existing logs into lower-confidence evidence signals for coverage analysis.

gov.ingest_log(log_entry, confidence="medium")
